# ☕ Coffee Machine (Python)

A simple command-line **Coffee Machine** application written in Python. Users can view a coffee menu, place an order, make a payment, and receive change if the payment is sufficient.

---

## 🚀 Features

- Displays a coffee menu with prices.
- Allows users to order:
  - Espresso
  - Latte
  - Cappuccino
- Accepts payment from the user.
- Checks if the payment is sufficient.
- Returns the remaining change.
- Allows multiple orders until the user chooses to exit.

## 📖 How It Works

1. Displays the available coffee menu.
2. Prompts the user to choose a coffee.
3. Accepts the payment amount.
4. Checks if the payment is enough.
5. If successful:
   - Prepares the coffee.
   - Returns any remaining change.
6. Repeats until the user exits.
